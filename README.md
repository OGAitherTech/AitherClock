# Aither Clock

A clean, responsive clock app built for the web and iPhone.

## Features

- Live digital clock with 12-hour and 24-hour formats
- Live analog clock with all 12 hour markers
- World clock section with major cities and time zones
- Stopwatch with laps
- Countdown timer with progress bar
- Saved alarms
- Dark and light appearance
- Custom accent colors
- Multiple background styles
- Rounded, soft, and square card styles
- Compact, normal, and large clock sizing
- System, monospace, and rounded font styles
- Analog + digital, digital-only, and analog-only clock layouts
- Fullscreen mode
- Appearance preferences and alarms saved locally
- Responsive iPhone/mobile layout
- No account or external API required

## Run

Open `index.html` in a browser, or publish the repository with GitHub Pages.

## Files

- `index.html` — app structure and settings controls
- `style.css` — responsive UI, themes, backgrounds, cards, and typography
- `app.js` — clock, world clocks, stopwatch, timer, alarms, and preferences
